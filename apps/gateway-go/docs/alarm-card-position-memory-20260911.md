# 返回入口与卡片位置记忆

- 全屏面板右上角使用左箭头及“返回原页面”，去除 × 图标；单张卡片关闭提示仍使用 ×。
- 拖动结束、方向键微调后，将相对告警列表区域的坐标保存到当前站点浏览器 localStorage。
- 按登录账号和规则分组 ID 隔离；分组 ID 包含父规则/设备/点位，不使用每次变化的事件 ID。关闭/重开、刷新页面、同一规则恢复后再触发都可恢复位置。
- 当前浏览器与网关访问地址内有效，不同步其他浏览器或 HTTP/HTTPS 来源；不保存到网关业务配置。
- 面板打开且布局尺寸有效时恢复；按实际视口约束卡片边界，避免跑到页面外。自动尺寸约束不覆盖原保存坐标。
- Home 清除单张卡片位置；“重置布局”清除当前账号全部保存位置（含当前未显示的规则），不清除其他账号/其他站点偏好。空面板也可重置。
- 存储不可用或损坏时不影响面板/拖动；丢弃无效坐标，位置保存采用尽力处理。
