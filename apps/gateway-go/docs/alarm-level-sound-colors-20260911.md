# 分级声音与自定义告警颜色

状态：2026-09-11 已部署 EG100 并通过实机验证。仅更新 Web 展示偏好，不修改服务端告警等级、判定、权限和历史记录。

## 设置

- 保留独立「声音设置」标签页，按提示（INFO）、警告（WARNING）、严重（CRITICAL）分别展示设置卡片。
- 每级支持声音开关、单次／持续循环、音色、音量、颜色、独立试听及恢复本级默认。声音总开关仍优先。
- 自动迁移旧版统一声音配置：原音色／音量／播放方式继承至各等级；原「仅严重」映射为提示及警告声音关闭。旧配置不会被悄悄启用更多等级。
- 多个告警从未静音、级别声音已开启、音量大于 0 的候选中选最高等级，按其音色与播放方式发声。关闭最高等级声音不阻止较低等级发声。
- 修改颜色不发声、不修改事件等级。颜色覆盖告警列表／历史／规则等级标识、行边缘、通知卡片边框与限值标签、面板统计、顶部及导航告警标识。
- 严重告警继续只闪烁边框，背景与文字不闪烁。保留文字等级，浅色徽标自动使用深色文字以保持可读。
- 颜色限定为六位十六进制，拒绝非法 CSS 值；音量限定 0～100。偏好按浏览器源站／账号保存，并跨主页面和独立告警标签页同步。
