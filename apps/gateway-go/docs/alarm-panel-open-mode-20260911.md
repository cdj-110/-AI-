# 告警面板打开方式

状态：2026-09-11 已随分级声音与颜色版本部署 EG100，实机新标签页打开及偏好同步验证通过；部署备份与验收信息见 `alarm-level-sound-colors-20260911.md`。

## 界面与策略

- 告警面板右上角增加「下次打开：本页弹出／新标签页」开关。默认本页弹出，按当前浏览器、源站及账号保存；切换不强制关闭当前面板。
- 新标签页使用独立入口 `/?alarmPanel=1`，只加载登录信息、告警快照及面板，不加载后台配置编辑页面。
- 新标签页模式遇到新告警优先复用既有告警页，不因轮询或新事件强制聚焦、重新导航或重复创建标签页。
- 浏览器阻止自动打开时只显示非模态提示和手动打开按钮，不退回全屏遮挡主页面，也不逐事件重复尝试。
- 用户关闭告警页后，后续新告警不会反复打开标签页。顶部告警按钮仍可主动重新打开；重新选择新标签页模式会重新允许下一次自动打开。
- 告警页继续单独读取快照。关闭主页面不影响已打开的告警页更新。
- 告警页在线时主页面停止发声，由独立页负责；独立页关闭后主页面恢复负责声音。浏览器仍可能要求用户在独立页点击启用声音。
- 静音、置顶、声音偏好通过同源存储事件同步；不改变后台告警规则、确认、恢复或记录。
- 在独立页中点击「告警管理」仅将该标签页切换到管理页面，不导航原工作页，避免丢失未保存编辑。

## 校验

- `verify-alarm-window-ui.mjs`：下一次打开开关、浏览器拦截、单标签页复用、主页面刷新后检测已有告警页、静音置顶共享、单页面声音职责、切回本页、关闭后不重复新建、无业务写入。
- 回归 `verify-alarm-panel-ui.mjs` 与 `verify-alarm-sound-ui.mjs`，保留拖动、位置记忆、边框闪烁、声音、静音与置顶功能。
- 前端类型检查和生产构建通过。

## 浏览器边界

- 浏览器决定是否允许后台打开及显示为标签页或窗口，首次拦截需手动点击或允许此站点弹出。
- 相同浏览器源站内有效；跨浏览器或 HTTP／HTTPS 不共享偏好。
- 在线标记每 2 秒刷新；主页面持有窗口引用时同时检查是否关闭。没有窗口引用时使用 45 秒标记有效期，浏览器长时间冻结后台页可能延迟在线状态判定。
