# 全屏告警面板：单卡片拖动

- 卡片标题含拖动手柄，支持鼠标/触摸指针拖动；方向键每次微调 16px，Home 恢复该卡片自动排列。
- “重置布局”恢复所有卡片；全屏面板本身不移动。
- 拖动后的卡片保留原网格占位，其他卡片不被该次拖动挤动。拖动坐标保存在以规则分组为 key 的卡片组件内，普通实时刷新和新增告警不重置；关闭面板再打开不保留坐标，不写网关配置或本地持久化。
- 浮动卡片限制在可见告警列表区域，不能覆盖标题/页脚。窗口缩小、卡片内容变高时重新约束边界；长卡片内部允许滚动，关闭与标题仍可到达。
- 卡片拖动时暂停该组提示计时，包括指针移出卡片的情况。鼠标抬起、指针取消、窗口失焦、组件卸载时清理拖动监听。
- 只改变展示，不确认或恢复任何告警，不修改阈值、权限、历史和采集逻辑。
