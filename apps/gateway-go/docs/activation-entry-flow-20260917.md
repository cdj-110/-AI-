# 激活与登录入口

- 无有效授权：首页显示待激活页，直接访问登录页也返回待激活入口。
- 授权有效：未登录用户访问首页进入正常登录流程，已有业务会话保持正常使用。
- 首次激活直接选择并导入签名授权文件，无需账号密码；有效授权后才进入正常登录流程。
- 已有授权记录（即使过期、损坏或授权文件被删除）更换授权仍要求管理员验证，复用原权限、登录限流和双因素验证。
- 匿名首次激活使用单独的 JSON 接口，只接受启用的 v2 签名授权包，不允许指定路径；完整签名、硬件/芯片绑定、有效期和防重放校验保留。预检不写文件，提交在锁内再次检查首次激活资格，防止并发替换授权。
- 成功导入后退出用于导入的会话，返回首页，授权有效后进入登录页面；需要重启时先等待网关重启。
- 密码错误、授权验证失败、导入会话失效均留在待激活页面，不能提前访问采集或业务界面。
- 必须修改初始密码的账号仍遵循原强制改密规则，不跳过安全限制。

本地前端构建、独立 Chrome 模拟验证和授权/登录/MFA/限流 Go 回归通过。
