# 网关检查首批修复记录

日期：2026-09-09。对应 `gateway-audit-20260909.md`，仅修改本地代码和构建产物，没有部署 EG100 / 219，也没有更改现场配置或清空数据。

## 本批完成

1. **配置权限边界**：完整配置、精简配置和工程导入按实际变化的模块检查权限；安全配置不得通过整包入口改写。其他模块保存时保留磁盘上最新的用户、密码和二次认证状态。
2. **边缘计算保存**：增加专用配置接口，单独授予边缘计算管理权限即可保存，不再借用全局设备配置权限；接口拒绝夹带其他模块字段。
3. **回滚结果**：配置应用失败后检查文件恢复和运行时恢复结果，失败时明确报错，不再无条件宣称恢复成功。当前配置不可读时停止保存。
4. **DL/T 645**：修正 2007 电能字典 DI，补充组合有功项；带符号 BCD 写入检查符号位占用、精度和越界；日期时间检查 BCD、日历和时间范围。已有显式 DI 与标准项冲突时给出诊断，不静默改写手动 DI。
5. **历史完整性**：异步队列改为先进先出，保留同一点位的中间采样及任务关联。容量包含在途事务，失败批次回到队首；队列满时计数并提示丢弃，不静默覆盖。默认最多 8192 条待写/在途采样，每批最多 512 条，达到批量阈值立即唤醒写入。
6. **只读体验**：告警、历史页面隐藏管理动作并禁用修改开关。历史接口提供最小设备目录，历史查看账号无需读取整包设备配置或设备凭据即可加载查询选项。
7. **未保存提醒**：点位配置、边缘计算、告警和历史设置注册页面离开提醒，支持继续编辑或放弃修改；关闭浏览器时使用原生未保存提示。
8. **趋势正确性**：历史及实时趋势使用实际时间间隔定位，异常质量/无效数据断开连线，避免把采集中断画成连续趋势。

- 已有 DL/T 645 标准项若出现 DI 冲突诊断，需要核对后重新选择标准点位，或明确改为手动 DI；不能仅凭 GOOD 质量判断数据项对应正确。
- 历史队列是有界内存队列，不保证磁盘持续故障、队列溢出或进程突然终止时零丢失；页面丢弃计数属于当前写入器生命周期，不是永久审计计数。
- 默认 Go 测试不等于启用原生 OPC DA / IEC 61850 扩展的交叉编译和实机验收。本批尚未验证真实电表、断线重连及长期高负载运行。
