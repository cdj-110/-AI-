# 同一规则四限告警合并通知

已在本地完成并验证，并于 2026-09-11 09:27 部署 EG100。

## 行为

- 同一父规则、同一设备及点位的多个限值共用一张弹窗通知卡片。上限、上上限（以及下限、下下限）在卡片内逐项显示，标题采用父规则名称和当前最高等级。
- 上限触发后再触发上上限，更新原卡片，不新增第二张；保留拖动位置，重新计算该卡片显示时长。普通数值刷新不重置计时。
- 部分限值恢复或被确认后移除对应提示，剩余未确认限值仍在原卡片显示；全部恢复/确认或关闭规则弹窗开关后收起。
- 手动关闭仅隐藏卡片，不确认、不恢复告警；轮询不会补弹原事件。若随后出现新的限值告警，可重新显示合并卡片。
- 不同规则不合并，即使名称相同。缺少父规则信息的旧事件仍按自身规则处理，不通过字符串后缀猜测父规则。
- 当前告警列表、告警计数、各限值的独立判定、恢复、手动恢复、声音提示和历史记录保持原有逻辑；仅合并弹窗呈现。

## 实现

- 四限展开时生成不写入配置的父规则 ID/名称、限值 key/名称；活动事件通过 parentRuleId、parentRuleName、limitKey、limitName 返回。
- 运行时元信息不参与规则签名，兼容已有手动恢复持久化状态，无需数据库迁移。
- 通知按稳定 groupId 挂载，刷新更新组内容；revision 只随新事件递增，配合定时器避免刷新导致永不关闭。
