# 按告警规则控制弹窗提醒

本地完成并验证，已于 2026-09-10 17:51 部署 EG100。包含此前回差帮助图标。

## 使用

- 告警规则新增/编辑窗口增加“弹窗提醒”开关，规则列表显示开启/关闭状态；点击“确定”后仍需“保存规则”生效。
- 新规则默认开启；旧配置未提供该字段时也默认开启，不改变既有行为。
- 规则绑定点位，因此可控制哪些点位的哪些告警弹窗；四限子告警继承父规则的设置。
- 关闭只影响弹窗，不关闭判定、告警计数、历史记录或提示音。已有对应弹窗在下一次轮询时收起，不确认也不恢复事件。
- 开启后只对后续新触发事件弹窗，不补弹当前存量告警。统一显示时长仍在“弹窗设置”配置。

## 实现和兼容

- 规则配置增加可选布尔字段 popupEnabled（缺省 true）；活动事件明确返回 popupEnabled=true/false。
- 弹窗开关不参与规则判定签名，热加载更新当前事件的提醒状态，不结束/重触发事件，也不清除已持久化的手动恢复抑制。
- 无需数据库迁移；同时修复无数据库模式下配置热加载清空内存历史的问题。
- 前端新事件检测和声音逻辑保持不变，只过滤弹窗队列；显式引用 TypeScript 模块以避免旧同名 JavaScript 文件遮蔽最新逻辑。
