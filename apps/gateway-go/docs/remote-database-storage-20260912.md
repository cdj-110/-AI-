# 远程数据库存储（第一阶段）

后续实机验收：PostgreSQL 见 `eg100-remote-storage-acceptance-20260912.md`；MySQL 8.4.11 已修复字符集连接问题并通过 EG100 实库联调，见 `eg100-mysql-acceptance-20260912.md`；SQL Server 2022 已通过 EG100 实库及中断补传，见 `eg100-sqlserver-acceptance-20260912.md`。下文“未部署/未实测”描述为首阶段交付时的状态。

## 范围

新增“历史数据 → 远程数据库”，独立于本地历史记录开关。首批提供 MySQL、SQL Server、PostgreSQL 专用表适配；不迁移原 SQLite 历史数据，不安装数据库到 EG100，不执行用户自定义 SQL。

本次只修改本地代码、构建及测试。**未部署 EG100，未修改现场数据库或网关配置。**

## 使用

1. 选择断网缓存位置与每任务容量（默认 16 MB、范围 4～1024 MB；最多 4 个任务）。EG100 系统分区空间有限，长期补传建议使用已验证稳定、容量足够的存储卷。
2. 新增目标：主机、端口、数据库、模式名、专用表、账号密码。数据库本身应提前创建。
3. 选择指定点位；每任务 1～2000 点。默认每 5 秒保存当时最新值、每批最多 100 条、数据库请求超时 10 秒。该周期不改变采集周期。
4. 默认启用 TLS 并校验服务器证书。CA 路径是网关上的文件路径，不是浏览器电脑路径。私有证书需部署 CA。关闭 TLS 仅适合可信隔离网络。
5. “测试连接”只检查连接、字段及主键，不建表、不插入。首次没有专用表可能失败，需按说明建表，或明确勾选“自动创建专用表”。运行账号通常需要 SELECT/INSERT，以及 MySQL 防重操作所需 UPDATE；首次自动建表另需相应建表/模式权限。
6. 新任务默认停用。编辑“加入草稿”后，点击页面“保存设置”才生效。切换标签或离开模块时，未保存内容会提示；轮询只更新状态，不覆盖草稿。并发配置更新使用版本检查，冲突时需重新加载。

账号密码在返回中掩码；`***` 只在任务编号、目标及账号未变化时保留旧密码，更换目标必须重新填写密码。只读用户不能配置或测试连接，也不会从此接口获得数据库凭据。

## 数据与表结构

自动创建专用表，默认表名 `gateway_samples`，模式为 PostgreSQL 的 `public` 或 SQL Server 的 `dbo`。只允许安全的字母/数字/下划线标识符。已有表必须包含以下字段，且 `record_id` 是单列主键；MySQL 表必须使用 InnoDB。不会自动 ALTER 现有表。

| 字段 | 内容 |
| --- | --- |
| record_id | 每次入队生成的 48 位随机十六进制记录号，补传时保持不变 |
| gateway_key / device_key / metric | 网关、设备、点位标识 |
| sampled_ms | 本次存储采样时间，Unix 毫秒 |
| received_ms / source_ms | 接收时间、设备源时间；未知为 NULL，不编造源时间 |
| value_type / value_json | 值分类与原始 JSON 文本 |
| integer_value | 整数精确十进制文本，保留 int64/uint64 全范围 |
| float_value / boolean_value / text_value | 浮点数、0/1 布尔值、字符串查询列 |
| actual_type / quality / unit / diagnostic | 实际类型、质量、单位和诊断 |

`value_json` 为文本字段而非厂商 JSON 类型，避免数据库重排 JSON 后干扰补传校验。复合值、特殊浮点值保留在该列；不能表示的超长、NUL 文本等拒绝入队并计数。保留已有 BAD/OFFLINE 状态，不把旧值伪装成新设备读数。

## 可靠性和限制

- 采样和远程写入运行在独立后台任务中，远程断连不进入采集调用链。
- 每任务 SQLite 持久队列，FULL 同步、DELETE 日志。远程事务提交且记录校验成功后才删除本地队列。提交结果不确定、重启、断网均重放原记录号，通过目标主键防重。
- 真正多行批量 INSERT；内部每个 SQL 语句最多 100 条，避免 SQL Server 2100 参数限制。一个配置批次使用一个事务。
- 本地入队按小块处理，发送队列每次读取额外受 2 MB 载荷上限约束，防止大量长文本同时展开造成内存峰值；“每批最多记录数”是上限而不是固定条数。
- 故障指数退避 1～60 秒；界面显示待补传、缓存载荷、最后成功、失败原因、下次重试，以及本次任务运行已发送/未入队数。
- 数据库文件受页数上限限制，载荷额度约为设置的一半，预留页和索引空间；运行还需预留回滚日志和至少 4 MB 空闲空间。容量不是保证可存储时长。
- 缓存满、存储不可写或空间不足时拒绝新采样并明确计数，**不覆盖已有待补传记录**；不能承诺无限离线不丢数据。
- 外部缓存按 UUID/挂载代次绑定，卷移除不回落到同名系统目录；重挂载重新打开数据库。不可读取旧缓存时禁止删除/改投目标。
- 修改目的库/表、删除任务、更换缓存卷或降低容量前，必须补传完成，单独保存为停用，然后确认待补传为 0。停用同时暂停采样和发送；不得将待发送数据静默转投新目标。
- 页面发送/未入队计数是本次任务运行计数，重启或任务重建会重置；队列记录本身持久化。
- 不承诺远程表永久保存（第三方数据库自身的备份、容量和保留策略由管理员负责）。远程表查询索引、归档、分区按实际负载另行设计。

## 扩展国产数据库

`internal/remotestore.Adapter` 将连接/建表/事务写入与队列、补传、权限、点位选择分离。后续适配需增加驱动和 SQL 方言、配置类型、界面选项，以及该产品/版本的实库验收。达梦、金仓、OceanBase 等目前没有声明为已支持；兼容模式不等于已经验证。
