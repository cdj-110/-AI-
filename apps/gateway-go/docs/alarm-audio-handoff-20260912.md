# 跨标签页告警声音及全部静音

已于 2026-09-12 11:04 部署 EG100（192.168.1.214）。

## 原因与修正

- 原 `useAlarmPanelWindow` 在打开新标签页后直接让主页面放弃声音，新标签页只有点击后才能恢复被浏览器暂停的 AudioContext，因此出现断声。
- 将面板是否打开与声音播放归属分离。已解锁的页面保持播放权，新标签页不抢占；同源同账号通过独立存储心跳协调。只有实际运行的 AudioContext 才能登记为播放页面。
- 页面关闭/上下文暂停时释放播放权；已解锁的另一个页面接续。异常退出由 45 秒心跳到期恢复。新页面尝试浏览器允许的自动播放，不等待可能长期挂起的 resume，避免阻塞告警刷新。
- 浏览器不允许自动播放且没有其他已解锁页面时，明确显示“启用声音”。网页不能保证绕过浏览器用户交互限制。不同账号分开协调；仅适用于同源、同浏览器存储可用的标签页。

## 全部静音

- 告警面板标题右侧新增喇叭图标，悬浮显示说明，选中显示静音状态。
- 静音当前所有未确认活动告警，不改变声音总开关，不确认/恢复告警；新事件仍可提醒。
- 再点取消当前全部静音；也可在单张卡片上单独取消静音。跨标签页同步，全部恢复后清理本次静音状态。
