# 告警规则弹框紧凑布局

## 修改

- 弹框桌面宽度由 720px 调整至最大 1120px。
- 顶部并排显示规则名称和关联点位；下方左右分区，左侧触发条件/四限，右侧回差、延时、自定义说明和三个开关。
- 回差、触发延时、恢复延时同行，字段高度调整为 34px。
- 标题和确认/取消固定在弹框上下方，超小视口只滚动表单区域，不裁剪内容。
- 保留新增/编辑逻辑、阈值校验、规则保存、拖动、回差说明和权限控制，未改后端及现场配置。

## 验证

- 前端类型检查和正式构建通过（原有大包体积提示仍存在）。
- 浏览器在 1920×911、1366×768、1280×720 下验证表单 scrollHeight 不大于 clientHeight，完整字段和底部按钮无需滚动即可看到。
- 单阈值模式、四限模式、手机 390×780 无横向溢出、手机底部按钮固定均通过。
- 原告警确认/恢复成功与失败、规则四限校验/保存、回差提示、弹窗策略、拖动和只读权限回归通过。
