# 紧凑分级声音设置与自定义音频

状态：2026-09-12 已部署 EG100，正式程序、页面资源及服务状态验收通过。

## 布局与行为

- 声音、颜色和音频选择改为草稿编辑，点击“保存设置”后才影响正在运行的告警并同步其他标签页；试听允许使用当前草稿。保存成功显示提示，存储失败保留草稿。
- 离开声音标签、切换左侧页面、退出登录时检查未保存内容，提供保存并离开、放弃修改、继续编辑。刷新或关闭浏览器使用浏览器原生未保存提示（浏览器不允许自定义保存按钮）。
- 上传中的音频也受离开保护；放弃草稿清理本次暂存文件，不删除原先已保存音频。其他标签页更新设置时保留当前草稿并提示冲突，禁止静默覆盖。
- 参考四限配置截图的逐行表单样式，声音设置从三张大卡片改为提示、警告、严重三行。每行排列声音开关、音色、循环方式、音量、颜色及试听／恢复默认，次要说明默认折叠。
- 保留现有四限规则紧凑三列布局和规则判定，无后端或数据库迁移。
- 新默认工业分级蜂鸣：INFO 单音、WARNING 间歇蜂鸣、CRITICAL 高低交替。可单独选择间歇蜂鸣、高低交替、扫频警笛，保留原有音色兼容旧偏好。旧用户已保存的音色不会被静默覆盖，可自行切换或恢复本级默认。
- 内置音色为浏览器合成的辅助提示，不宣称符合某一工业安全认证标准，也不替代现场声光报警器。
- 上传 MP3 / WAV / OGG，最大 2 MB、30 秒。检查扩展名、非空、大小和真实解码时长；校验成功并保存后才替换旧选择，失败保留旧文件和设置。
- 上传后该等级自动选用自定义音频，可替换、移除或重新选择内置音色。自定义循环使用完整 AudioBuffer 循环，不受内置两秒重复周期截断或叠加；确认、恢复、静音、关声或声音归属变化会停止音源。异步加载期间取消不会延迟重新发声。
- 自定义文件使用当前源站的 IndexedDB，按账号命名空间隔离；设置只保存文件引用。与现有偏好一致，不上传服务器，不跨浏览器同步；清理站点存储后需重新上传。该隔离是产品偏好隔离而非同源脚本安全边界。
- 已保存文件无法读取／解码时，显示说明并回退到内置工业分级蜂鸣。上传／偏好保存失败显示错误，不冒充保存成功。
