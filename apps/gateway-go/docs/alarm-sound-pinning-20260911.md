# 告警声音与卡片置顶

本次仅调整 Web 前端，不修改告警配置接口、规则或记录。2026-09-11 14:23:55 已部署 EG100（192.168.1.214），并完成实机验证。

## 行为

- 告警管理新增独立「声音设置」标签页，与弹窗设置分开。
- 支持开关、持续循环／新告警单次、分级提示音／双音铃声／蜂鸣、音量、全部等级／仅严重、试听及停止试听。
- 默认开启，持续模式每 2 秒播放一组提示音；同一时刻只播放未静音告警中的最高等级，不叠加不同卡片的声音。
- 声音独立于弹窗，关闭卡片、关闭面板或弹窗超时不意味着静音。确认、恢复、单条静音、声音总开关关闭会停止对应声音。
- 卡片可单独静音或取消静音。静音按当前事件 ID 保存，同规则新事件或新限值不会被之前的静音永久屏蔽。
- 卡片支持置顶／取消置顶。置顶优先排列，重叠时高于普通卡片；置顶暂停自动关闭，仍可手动关闭提示，不阻止确认或恢复后移除。
- 置顶、声音设置以及本次事件静音状态按浏览器源站和账号保存。位置沿用原来的规则分组位置记忆。
- 浏览器自动播放被拦截时显示「启用声音」，用户点击允许后只播放仍然有效的告警；过期提醒不会补播。
- 本功能使用浏览器声音，不是网关硬件蜂鸣器。需要网页和电脑保持运行，后台节流、系统静音和休眠可能影响播放。
