智能网关

从左侧选择串口、网口或设备，右侧只展示当前对象的相关配置。

接口配置

先维护网关上的串口和网口，后续设备可按现场接线关系挂到对应接口下。

串口配置

适用于 RS485 / Modbus RTU。

网口配置

适用于以太网 / Modbus TCP。

设备与点位配置

先配置设备连接，再在设备下维护点位，结构更贴近现场采集关系。

云平台连接

配置 MQTT 云平台连接。停用后网关只做本地采集和展示，不会上报数据。

手动 MQTT 连接

可创建多个手动 MQTT 通道，不同通道连接不同平台并上报同一批采集数据。

微控云连接

使用云平台下发的激活文件连接，通常用于设备预注册和自动绑定。

批量修改

单击表头选择列，右键打开批量操作。
