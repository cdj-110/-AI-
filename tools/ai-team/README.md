# 微控 AI 研发调度原型：Codex 登录模式

本地调度器通过 Codex CLI 使用已有 ChatGPT 登录，不要求配置 OPENAI_API_KEY。规划、开发和审查依次调用同一登录下的 Codex；人工审批不由模型代替。

2026-10-14 实测：独立安装的 Codex CLI 0.162.1 返回 CODEX_READY，退出码为 0。WebSocket 请求超时后自动回退 HTTPS 成功。原内置 CLI 0.135.0 不支持当前配置模型，未修改桌面应用安装。

调度依赖已安装，4 项单元测试通过，覆盖路径边界、原仓库不变、审核拒绝、缺少代码测试镜像阻断。测试使用固定输出，不能当作真实 AI 任务验收。

当前仅为原型：未完成真实需求到 PR 的闭环；未接入自动推送或合并；未完成最新源码 Linux CI。配置中的隔离仓库来自 GitHub 旧基线，必须先完成本地最新源码的筛选与刷新，才能用于正式研发任务。代码任务没有配置经验证的测试镜像时必须失败。

本机配置 config.local.json 不纳入版本控制。任务状态和日志保留在配置指定的 state_dir；其中可能包含源码，不应随公开源码上传。运行入口为 team.py doctor、team.py run --task pilot-task.json、team.py serve。启动服务前需要明确配置正确的隔离基线。

数据库事实：云平台业务数据 PostgreSQL，时序数据 TimescaleDB；Go 网关 MySQL 是输出能力。Q-01 已关闭，不涉及数据库迁移；生产版本和部署证据待核实。
