# 事件属性编辑实时预览

候选变更：feat: 支持事件“更新属性”编辑面板的实时画布预览。工作树变更，未创建正式提交、未部署，保留此前修改。

此前面板只编辑目标组件副本，画布仍渲染原始 Store 数据。现在编辑画布使用临时响应式属性覆盖层，递归支持分组子组件。原始组件、项目保存、撤销记录和运行预览不读取此覆盖层。

打开面板时优先展示事件已保存的属性；改变颜色、线条粗细、尺寸或滤镜会实时反馈。取消、遮罩关闭、切换画布、组件删除和面板卸载会清除预览。保存只更新事件快照并清除预览，属性在运行事件触发时生效。部分组件 setup 中使用 toRefs 固定对象引用，因此进入/退出预览重建组件一次，连续编辑保留本地配置引用。

事件列表只渲染一个属性面板，避免多个事件共用 show 状态时重复弹出。已有事件重新编辑时使用同一事件草稿引用，避免保存时丢弃面板修改。

验证环境：Windows，本机临时 3029 预览、独立 Chrome 无头浏览器，模拟项目与接口，无真实凭据或业务写入。

- `node tools/test-event-attribute-preview.cjs`：通过，分组子组件覆盖、持续编辑稳定引用、原始数据不变、取消恢复、事件快照保存/重新打开、切换画布与卸载清理。
- `node tools/test-event-attribute-browser.cjs <bundled-playwright-path>`：通过，实际编辑线条粗细 5→12 时立即渲染；取消恢复 5；保存 18 后恢复默认 5；重新编辑显示 18；两个事件仅出现一个面板，无浏览器 pageerror。
- `npm run build`：构建通过。此 Windows 脚本不能证明独立类型检查通过；已有依赖类型版本兼容问题仍未解决。

临时预览已停止。未测：每个图表组件的全部属性组合、真实项目运行时事件与实时数据叠加。测试验证事件草稿及画面变化，不代表正式项目发布验收。
