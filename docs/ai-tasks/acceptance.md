# 研发任务验收说明

- **范围**：仅修改任务授权路径，保留已有修改；不得涉及凭据、策略、CI 配置或无关文件。本任务仅创建 `docs/ai-tasks/acceptance.md`。
- **数据库边界**：Go 网关支持 MySQL 输出；云平台业务数据库为 PostgreSQL，时序数据库为 TimescaleDB。网关 MySQL 输出能力不代表云平台数据库迁移。
- **验证门禁**：按变更范围执行必需的类型检查、测试和构建。任一失败必须阻止交付；必需验证未执行或结果不明时不得验收通过。构建成功不能替代类型检查成功。
- **真实记录**：记录验证命令、环境、结果及未测范围。未执行项标记 `not_run`，不得声称通过，不得用历史报告替代当前验证。
- **提交与 CI 绑定**：记录最终候选提交的完整 SHA、对应 CI 运行链接及结果，确认 CI 验证的是该提交。提交变化后，须针对新提交重新执行必需验证并重新人工审核。
- **交付材料**：列明候选提交、行为变化、验证记录、未测范围、风险和回滚方式。
- **最终审核**：审查者核对授权路径、数据库表述、验证门禁及提交与 CI 的一致性，拒绝不安全、不完整、无关或前后不一致的变更。最终由人工审核；AI 不得自行批准合并或发布。审批须绑定最终提交、制品、目标环境和迁移配置（如适用），不得替代实际权限门禁。
