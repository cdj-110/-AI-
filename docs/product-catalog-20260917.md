# 管理平台产品库

管理平台新增独立菜单“产品库”，仅超级管理员可管理。

## 型号规格

- 固定型号编码、产品名称；编码保存后不可改名。
- 网口、RS232、RS485、CAN 数量分别记录：0～64，留空表示待确认。CAN 是独立总线接口，不计入串口数。
- 4G、WiFi 支持：支持 / 不支持 / 待确认，避免未知规格被误判为不支持。
- 启用状态、规格说明；说明可记录接口类型、选配模块等。
- 已引用的型号禁止删除，可停用以阻止后续出厂登记；现有网关不受影响。

出厂网关登记从启用的产品型号中选择，展示规格摘要，自动生产批次使用选定型号。后端同时校验产品存在且启用，数据库外键禁止悬空型号引用。产品增删改写入操作日志。

迁移 `20260917033000_product_catalog` 保留所有已有型号引用，不改旧批次。预置 EG100（2 网口、2 串口；无线能力待确认）；若旧档案已存在该型号，优先保留迁入规格的待确认状态，不猜测旧产品能力。

本阶段是规格管理及登记关联，不会自动限制网关运行功能、重写网关网络资源、改变已有授权文件或配置。型号规格尚需与正式硬件 BOM 核对。

## 验证

API 与管理端构建通过。独立临时 PostgreSQL 验证完整迁移、旧型号升级保留、CRUD、重名、引用删除保护、禁用/未知型号登记拒绝、三态能力及批次编号；授权安全回归通过。

独立浏览器使用模拟接口验证产品增删改、型号编码锁定、搜索、能力选择、无启用型号时登记阻止，以及完整设备身份一次粘贴回归。正式平台与 EG100 未修改。

正式部署需备份数据库、执行迁移，并更新 API 和管理端；EG100 不需要更新。
