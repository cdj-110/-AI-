# 自动生产批次

登记出厂网关时，生产批次留空默认生成 `YYYYMMDD-型号-序号`，例如 `20260917-EG100-001`。

- 日期统一使用北京时间；同一天、同型号独立递增，次日从 001 开始。
- 型号默认 EG100，可手动更改；批次也可手工覆盖。
- 登记成功时由服务端分配实际编号，页面示例并非预占编号。
- 分配计数与档案写入处于同一数据库事务，失败不会占用编号。
- 删除或移除档案不会删除计数；升级时读取相同前缀的历史批次接续。
- 序号至少三位，超过 999 后自然增长，不截断。
