# ADR-001：网关输出与云平台存储边界
状态：accepted（用户明确确认架构用途，非生产验收）
日期：2026-10-09（Asia/Shanghai）
确认者：本聊天用户

决策：Go 网关支持 MySQL 数据输出；云业务数据采用 PostgreSQL，云时序数据采用 TimescaleDB。
背景：先前将网关输出能力与云平台选型混为一谈，形成 Q-01。
影响：关闭 Q-01；更正旧云平台 MySQL/InfluxDB 口径；保留网关 MySQL 输出功能。
迁移：无，本次为知识修订。
验证边界：用户确认与本地清单/源码证据一致；未连接生产，运行版本仍为 Q-02。
来源 S-21：用户消息“Go 网关的数据能够向mysql写数据，云平台的数据库就是PostgreSQL／TimescaleDB”及后续确认文本。
