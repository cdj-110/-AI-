# 数据中心网关点位归属修复（2026-10-13，已本地部署）

## 范围与原因

网关点位接口汇总其自身和有权访问的子设备点位，但历史任务编辑器此前忽略返回的deviceId，统一按所选网关提交。网关自身没有这些指标，因此历史校验拒绝。没有修改点位启用状态或历史数据。

## 候选改动

- DevicesService.metrics：网关汇总返回实际所属设备名称及自身指标标识，保留deviceId。子设备范围仍使用deviceAccessWhere独立过滤，不因为能访问网关而放宽权限。
- HistoryTaskEditor：按实际设备分组显示点位，标签显示设备/点位；选项键使用设备ID与标识符组合，避免不同子设备同名点位冲突。保存按实际所属设备提交，网关/子设备重复选择同一点位自动去重，最多20个唯一点位。
- 历史查询错误列出已通过设备访问校验的具体设备名/标识符，不泄露无权限设备。
- 任务保存后按实际子设备恢复条件；移除网关仅移除该入口的选择，不影响其他入口仍选中的点位。没有将旧任务猜测性迁移到子设备；旧错误配置需重新选择后保存。
