# 线-01 第一批优化

候选变更：feat: 将线-01 改为可编辑 SVG 线段。工作树修改，未提交正式 Git 提交、未部署，保留此前工作树修改。

绘制由矩形 div 改为 SVG line；兼容旧数据的 borderColor/chuxi 字段及无 lineVector 的水平线，保留旧容器尺寸与顶部线条位置。删除绘制组件反向写高度和重复写坐标的 watcher。几何编辑使用可序列化的 lineVector 和实际起终点计算包围盒，支持水平、竖直、斜线及反向线段。

属性面板提供线条颜色、正数粗细（0.5—100）、长度、角度、实线/虚线/点线、平头/圆头、起点与终点箭头。几何/装饰变化保持线段起终点位置；新增字段缺失时保持原水平实线。原默认尺寸 300×5 不变。

编辑时用两个端点代替矩形八个缩放锚点。Shift 将方向约束到 45° 的整数倍，支持水平、垂直、斜线；拖动按帧合并，鼠标松开提交最后坐标。Escape 取消，退出清理监听器，拖动临时锁定画布缩放。端点拖动记录完整属性快照，补齐 UPDATE 撤销/重做交换处理。

透明命中路径保持至少 12 屏幕像素宽；不放大可见线条、不让斜线包围盒空白区域截获鼠标；端点保持约 9 屏幕像素，箭头的可见区域亦可选中。编辑命中路径仅编辑器启用。

普通属性面板和事件属性面板均传入线段几何数据，支持临时预览与保存事件快照。分组内线段绘制保留原有分组行为；分组未拆开时不提供子组件端点操作。
