## 行为

- 网关通过现有 factory MQTT 安全心跳上报授权摘要：启动/重连成功后立即发送，正常连接期间每 15 秒发送一次。离线缓存积压不再直接跳过授权心跳。
- 管理平台出厂网关列表新增独立授权状态、签发序号/设备实际序号、最近授权回执；悬浮提示包含首次确认激活时间和有效期。使用列表原有刷新按钮获取最新展示。
- 签发文件不等于设备已导入：无回执显示“待设备确认”。收到当前签发序号有效回执才显示“已激活”。重新签发保留设备旧回执，显示“待更新确认”。
- 回执超过 90 秒未刷新仍保留最后确认状态，并明确提示不代表当前在线；授权到期以平台时间判断。绑定状态独立展示，不再用旧心跳推断激活。
- 首次激活时间是平台首次收到当前授权有效回执的确认时间，不是设备本地导入时间。老设备升级后首次上报才记录，不伪造历史。
- 重新登记已移除设备会清空旧授权回执和首次确认时间；普通重新签发保留首次确认时间。

## 协议与边界

主题 `weikong/factory/{hardwareId}/heartbeat` 的 JSON 增加 `authorization`：
`sn / hardwareId / chipUsid / licenseVersion / licenseSequence / keyId / licenseId / issuedAt / expiresAt / features / valid / restricted`。

`licenseId` 是签名字符串的 SHA-256 摘要；不传签名原文、连接密码、设备密钥、原授权文件或云连接参数。按 broker 认证和 ACL 限制的主题选择设备记录，再校验摘要身份和签发元数据；声明的设备身份不能选择其他数据库行。

限制消息大小、字段类型、序号范围；当前签发有元数据时比较文件指纹、密钥版本、签发/到期时间、功能列表。事务写入同时校验签发序号与登记状态；拒绝过时接收时间以及低于已确认设备序号的延迟回执，防止旧消息覆盖新状态。

回执属于已认证连接上的状态确认，不是对已被 root 攻破设备的远程硬件证明。未启用云连接或不联网的设备不能让管理平台知道本地激活结果。未授权/启动时已过期的维护模式仍不启用云连接，本功能不放宽授权限制。
