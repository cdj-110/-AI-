## 9. 开发交接清单

交给公司开发前，建议确认以下内容：

- 目标硬件平台和可读取的唯一 ID 来源。
- MQTT Broker 部署方式和认证回调方式。
- 是否需要 HTTPS、证书和公网域名。
- 是否允许工厂阶段访问云平台。
- 客户绑定是否只允许租户管理员操作。
- SN 编码规则是否包含批次、年份或产品型号。
- BindCode 有效期和错误次数限制。
- 激活文件是否需要数字签名。
- ARM Linux 的 CPU 架构、内存、存储和系统版本。
- 工厂批量烧录方式，是网页上传、U 盘导入，还是命令行工具。
