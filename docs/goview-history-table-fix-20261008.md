# GoView 基础分页表格修复

2026-10-08 完成，尚未部署。

- “基础分页表格”固定使用历史数据绑定；编辑画布继续展示保存数据或组件示例数据，历史查询在预览/发布页面执行。
- 新增 GoView 兼容历史查询接口 `POST /api/conf/influx/analysis/query/v3_2`，支持最多 20 个设备点位、最长 31 天、最近 500 条遥测记录，并遵循租户、子账号设备和设备分组授权范围。
- 表格结果统一为 `dimensions + source`，列包含时间、设备以及选中的点位；时间按 Asia/Shanghai 展示。
- 修复历史请求结果未写回组件的问题，并兼容列定义字符串、对象以及直接数组数据，避免格式不完整时组件白屏。
- API 与 GoView 生产构建通过。GoView 构建仍包含上游循环分包和第三方 `eval` 警告，不影响本次构建完成。
