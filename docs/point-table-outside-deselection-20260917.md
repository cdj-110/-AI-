# 点位表格点击空白取消高亮

通用协议点位表格和 OPC DA 表格统一监听页面主指针按下事件。点击当前表格外区域时，清除行、列高亮及对应选择状态，避免实时刷新重新绘制已取消的高亮。使用捕获阶段监听，外部组件阻止事件冒泡也不影响取消操作；列宽拖拽期间和非主键操作不会误清除。

仅取消视觉高亮，不清空复选框批量选择、不修改单元格内容、不重置列宽。

验证：`verify-table-width-persistence.mjs` 覆盖 Modbus、S7、OPC UA、IEC 61850、IEC 104、GOOSE、DL/T 645 和 OPC DA 的行列取消、实时刷新、复选框、编辑以及列宽保持；前端类型检查和生产构建通过。

本次未部署到 EG100。
