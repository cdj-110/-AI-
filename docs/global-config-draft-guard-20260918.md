# 网关全局未保存配置保护

## 行为

- 对比读取或成功保存后的基线，只有实际编辑才提示；缺省参数补齐、运行状态和点位计数更新不算编辑。
- 切换设备配置/点位配置、点位分类、其他资源/通道/设备、功能页面及退出登录时，提供“保存修改并继续”“放弃修改并离开”“继续编辑”。
- 保存失败或校验失败保留草稿并停留在当前位置。编辑后恢复原值不再提醒。
- 大点位模式保护行参数和正在编辑的标识符，先处理点位草稿，再处理设备/通道配置。
- 重新加载与工程导入同样检查草稿。刷新或关闭浏览器使用浏览器标准离开提醒。
