# EG100 远程维护

管理平台为已激活且最近两分钟内在线的出厂网关提供两项独立操作：

- **重启网关服务**：仅重启 EG100 应用服务，操作系统与网络接口不重启，业务连接会短暂中断。
- **重启网关**：重启整台设备，网关重新上线前不能采集、转发或接受远程操作。

## 安全与可靠性

- 仅管理平台超级管理员可以发起，前端与接口均需二次确认。
- 平台先写入操作日志，再通过设备专属 MQTT 身份发送不保留的维护指令。
- 指令带唯一任务号、设备 HardwareId、签发时间和 60 秒有效期；设备严格校验设备身份和时间范围。
- EG100 在执行前持久化任务号，同一任务即使因 MQTT 重发、断线重连或服务重启再次到达，也只执行一次。
- EG100 先回传“已受理”，再延迟三秒执行，使平台能够显示明确结果。未成功上报的回执会落盘并在重连后补发。
- 平台记录 `PENDING / SENT / ACCEPTED / FAILED / TIMEOUT` 状态，整机重启后的重新上线由最近心跳确认。

## 上线顺序

1. 对管理平台数据库执行 `20260921170000_gateway_remote_maintenance` 迁移。
2. 更新管理平台 API 和管理端页面，使 MQTT ACL、任务接口和操作入口生效。
3. 将包含远程维护处理器的新版本通过 OTA 更新到 EG100。

当前代码只完成实现与本地验证；在未完成以上三步前，管理平台不会向旧版网关开放有效的远程维护能力。
