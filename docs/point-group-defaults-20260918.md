# 默认打开有点位的分类

- 普通点位工作区按已有分类顺序选择第一个非空分类，而不是按配置文件中的点位顺序。
- Modbus 依次检查 01、02、03、04；仅 03 非空时显示 03，01 非空时始终优先显示 01。
- IEC104 依次检查遥测、遥信、遥控、遥调、遥脉；没有分类的其他协议直接显示全部点位。
- 有点位时默认进入点位配置；无点位时进入设备配置。设备切换、协议切换和重新加载重新确定默认分类；手动切换分类后不因点位刷新而跳回。
- 大点位工作区先通过已有分页接口查询分类完整总数（每次最多返回一个点位），避免第一页未包含低序号分类造成误判。该工作区未分组的协议仍显示全部点位。不需要新增后台接口。
- 初始化及分类切换只修改界面状态，不写入网关配置；异步旧请求不可覆盖新设备或用户手动选择。

验证：默认分类单元测试、独立 Chrome 覆盖所有现有协议及普通/大表格、空点位、延后加载、手动切换及旧请求场景；配置未保存判断回归和前端类型检查/生产构建。

本次未部署到 EG100。
