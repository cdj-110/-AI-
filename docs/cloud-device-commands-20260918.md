# 云平台点位下发

入口为租户云平台「设备管理 → 采集子设备 → 实时数据 → 单个可写点位卡片的『下发』」。弹窗锁定所点击的点位，输入值并二次确认后，经该子设备所属网关的 MQTT 安全通道写入。超级管理员和租户管理员可操作，普通租户用户不可操作。只读点位不显示入口，离线时禁用；不会因请求点位不存在而自动改选其他点位。

点位读写能力以所属网关上报为准，无需再编辑云平台物模型权限；仍检查启用、未忽略、受支持的数据类型及角色/租户/网关归属。子设备物模型中的权限自动展示，不能手动覆盖网关能力，名称、单位、精度、排序、忽略状态等仍可编辑。当前复用 EG100 的 Modbus RTU/TCP 线圈及保持寄存器、OPC DA 显式可写点位、DL/T 645 显式可写点位。其他协议没有网关写入实现时不会开放下发。未绑定网关的直连设备和转发点位暂不支持本入口。

网关在拓扑指标和远程配置快照中明确上报 `canRead`、`canWrite`，通过 `pointAccessVersion: 1` 标记完整能力报告。云端优先使用拓扑能力，点位删除、改只读或子设备不再上报时不能回退至旧快照继续写入。遥测接收和拓扑报告自动批量同步指标权限，指标查询也实时覆盖权限，解决先报拓扑、后注册遥测指标的先后顺序问题。保留 `pointWriteVersion: 1`、`writablePoints` 兼容上一版 EG100；完全没有能力报告时提示更新网关。卡片能力后台每 15 秒刷新，弹窗打开时立即重新验证，打开后每 2 秒刷新能力和所选点位的回执。

本轮卡片入口与自动权限改动已于 2026-09-18 13:03–13:10（北京时间）同步发布并验收。此次没有新增数据库字段，数据库 33 项迁移状态为最新，未执行新的迁移。已更新 API、遥测接收（ingest）、租户前端及 EG100；下方 11:29–11:32 记录保留为上一版下发功能的发布历史。

任务保存至 PostgreSQL `DeviceCommand`，先记录审计再发送。MQTT 发送确认不等于执行成功，页面根据回执显示等待、成功、失败；30 秒没有回执显示结果未确认，提醒核实实际值、不要盲目重试。有效的迟到回执可消除超时的不确定性；成功或失败的最终结果不可被后续重复回执覆盖。弹窗关闭时停止回执查询，退出设备页面后停止能力轮询；最近记录按所选点位过滤。

按数据库设备 ID 与所属网关 ID 定位，再使用网关内子设备编号和点位标识进行执行。网关 Topic、任务 ID、子设备编号及点位均参与回执校验。请求 UUID 去重；网关执行前持久化保留指令编号，重连和重启不重复执行，崩溃中断保留未知状态。拒绝 retained 消息、过期命令、禁用点位及未授权的云端操作。不自动重发指令，也不会改变原始值的精度。
