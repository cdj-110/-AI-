# 云平台布尔点位下发选择

## 原因

实际点位 mbtcp_P01 的旧云端指标记录为 NUMBER，网关当前拓扑上报为 bool。下发能力接口沿用旧记录，导致实时卡片显示 true，但下发弹窗仍显示数值输入框。

## 修改

- 子设备点位类型优先使用所属网关当前上报的拓扑类型；未知类型保留旧类型，原有租户隔离和可写权限校验不变。
- 布尔点位使用 true / false 两个明确选项，每次打开都需要主动选择，未选择不能提交。
- 请求发送原生布尔值；后台拒绝把数字 0、1 或文本 true、false 作为布尔下发值。
- 数值、字符串点位保持原有输入方式，确认和回执机制不变。
- 不修改已有数据库指标记录，不需要数据库迁移。

## 验证

- API 设备下发回归测试通过，覆盖旧 NUMBER 记录与网关 bool 上报不一致的情况，以及布尔值校验。
- 独立 Chrome 自动化通过，覆盖 true / false 选择、未选择拦截、确认取消、类型正确、重复提交防护、离线拦截和结果回执。测试使用模拟接口，未写入真实设备。
- 租户平台和管理平台构建通过。
