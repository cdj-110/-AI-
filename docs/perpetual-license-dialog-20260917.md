# 永久授权与导入确认弹窗

## 行为

- 新签发、重发授权默认永久有效。`ACTIVATION_LICENSE_DAYS=0`；正整数仍可签发限时授权，负数、非整数、异常值拒绝签发。
- 永久授权使用 V2 原有签名载荷中的 `expiresAt: ""`，不是用遥远日期模拟永久。数字签名覆盖此字段；移除限时授权的到期时间会使验签失败。
- 旧授权文件不修改、不自动延长。要把现有十年授权变为永久授权，必须在管理端重新签发并导入新的 `.lic` 文件。
- 设备身份绑定、可信签名密钥、授权序号、防重放及权限校验保持不变。永久仅表示没有到期日，不意味着取消这些校验。
- 管理端接收永久授权状态回执后正常确认为已激活；当前序号的回执仍须匹配签发指纹、有效期、密钥和功能。缺失或无效回执字段不视为永久授权。
- 初次激活、授权替换和云连接页面的导入确认弹窗统一展示设备、序号、有效期。限时授权以本地中文日期显示；永久显示“永久有效”。管理端详情和网关授权面板也统一显示。

## 验证

- API、接收服务、网关页面和管理平台构建通过。
- API 签名安全、永久默认、显式 3650 天兼容、异常配置及授权状态测试通过。
- 接收服务永久回执解析、元数据防伪、首次激活确认、重复回执和受限状态测试通过。
- Go config / cloud / web 测试通过，包括永久签名验证、修改有效期拒绝、永久状态上报和导入接口。
- 独立 Chrome、模拟接口完成桌面/手机弹窗、日期格式、永久展示、首次激活、授权替换、取消、权限及无闪屏回归。
- 管理端模拟数据验证已签发/设备回报有效期均显示永久，以及抽屉刷新、手机布局、固定操作区和滚动回归。

## 发布说明

本次尚未部署。需要同步更新 API、接收服务、管理平台前端和 EG100 前端；不需要数据库迁移。当前根目录 `.env` 没有显式有效期覆盖项，更新 Compose 后使用新的永久默认值。生产环境若有显式 `ACTIVATION_LICENSE_DAYS=3650`，发布时应只将该项改为 `0`，保留所有其他凭据和配置。

网关构建针对确认模块锁定 TypeScript 源文件，防止旧生成的 `confirm.js` 覆盖新确认字段；其他弹窗继续使用原有样式。
