用户要求默认自动识别，也可切换手动设定。新配置默认valueMode=auto；没有该字段的旧配置也按自动模式处理，旧valueType字段保留但不再决定状态和下发。

自动识别优先使用绑定点位的TypeOptions.dataType，允许下发时以网关capabilities.dataType为准；结合原始实时值，支持原生BOOLEAN、NUMBER的1/0、STRING的ON/OFF、true/false、1/0及常见大小写配对。特殊数值5/2或任意文本RUN/STOP不猜测，标记未知并阻止控制。没有有效值时等待上报，不把未知值当false。

手动模式可选BOOLEAN/NUMBER/STRING并分别设置不同的打开/关闭值，包括布尔反向映射。显示和下发共用同一映射，不再仅修改UI。手动值类型必须匹配网关实际类型，非法/相同值、非有限数值或过长文本不能下发。模式切换保留手动值配置；旧非标准值用户需明确切换手动，避免推测控制语义。
