# 组态事件：满足条件触发（2026-10-14，已本地部署）

## 范围

新增事件触发方式“满足条件”，复用现有固定值/组件联动条件和事件动作。支持全部/任意条件，以及等于、不等于、大于、大于等于、小于、小于等于。数字计数可选择其 `dataset` 属性与数值阈值比较，例如大于 40。

仅在预览/运行中判断，编辑器不执行动作。首次有效条件满足或不满足转为满足时执行一次，持续满足不重复；恢复为不满足后可再次触发。缺失或无效数据不会触发，也不会将已满足状态重置。未配置条件不允许保存此触发方式。条件组合重新打开可恢复，全部/任意选择会保存。

使用现有事件动作分发，没有增加设备命令请求，也没有增加开关逻辑状态联动动作。现有更新属性动作跳过 `option.dataset` 的行为保持不变，因此仅新增触发方式不等于完成开关显示状态切换。此功能是页面运行时事件，不是云端持续运行的联动规则；首次判断使用组件当前属性值，未增加遥测新鲜度保证。
