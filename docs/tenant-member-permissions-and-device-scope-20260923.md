# 租户成员功能权限与设备范围

## 授权模型

租户管理员创建或编辑成员时，可以同时设置两类权限：

- 功能权限：按照“菜单 → 页面 → 按钮”三级树分配。页面访问与新增、编辑、删除、分组管理、告警处理等操作可分别授权。
- 设备范围：全部设备，或指定设备范围。

指定设备范围支持同时选择设备分组和单台设备，最终可访问范围为两者的并集。

新增或编辑成员采用三步流程：基本信息、权限配置、设备范围。默认只授予 7 个业务页面的查看权限，不默认开放修改类按钮。

## 按钮权限

- 设备管理：新增设备、编辑设备、删除设备、管理设备分组。
- 物模型管理：新增或复制模板、编辑模板和字段、删除模板。
- 告警管理：处理告警。

按钮权限自动包含其所属页面的访问权限。后端会规范化保存结果，防止产生“有按钮权限但无法进入页面”的无效组合。

## 分组授权规则

分组授权是动态授权。设备加入已授权分组后，该成员自动获得访问权限；设备移出该分组后，如果没有单台设备授权或其他分组授权，访问权限自动收回。

删除分组会同步删除该分组授权记录，但不会删除设备。设备原有的单台授权仍然有效。

## 安全规则

- 分组和设备必须属于当前租户，跨租户分配会被后端拒绝。
- 后端在设备列表、设备详情、状态流、告警、事件、仪表盘和远程管理接口执行设备范围校验。
- 功能权限同时由前端菜单和后端接口校验，隐藏菜单不能替代后端鉴权。
- 具有按钮权限的成员执行操作时仍受设备范围限制，不能处理未授权设备或告警。
- 已有成员保留原有页面查看权限和设备范围，不会因升级自动获得新增、编辑或删除权限。

## 自动验证

在 `apps/api` 下运行：

```text
npm run test:tenant-user-device-scope
npm run test:tenant-user-action-permissions
```

测试覆盖单设备授权、动态分组授权、跨租户隔离、权限更新、兼容默认值，以及菜单/页面/按钮的接口级鉴权。
