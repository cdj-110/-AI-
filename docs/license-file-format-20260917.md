# 对外交付授权文件扩展名

新登记和重发授权的管理平台下载统一使用 `activation-{SN}.lic`。内部仍是原有 JSON 文档，下载内容和数字签名不变；扩展名不提供额外加密或防破解能力。

待激活页面、系统维护中的设备授权以及云连接中的原授权导入入口均接受 `.lic`、`.json` 和 `application/json`。文件按原有流程读取文本、解析 JSON，并由服务端验证数字签名、实体设备身份、有效期和授权序号。旧文件无需改名或重新签发；仅把不合法文件改名为 `.lic` 不会绕过校验。

设备内部的配置路径和不可变授权文件名继续使用原有 `.json` 约定，不修改当前授权、授权防重放记录或设备配置。授权版本、签名密钥、通信载荷、数据库均不改变，本次不需要迁移。

验证：管理前端和网关前端构建通过；隔离浏览器验证登记及重发下载 `.lic` 后内容与接口原文一致，并验证 `.lic`（通用二进制 MIME）首次激活、更换授权与旧 `.json` 流程，错误签名、权限、取消、登录跳转和重启动画回归通过。
