## 行为

- 普通拖动四角/边：内容与容器同步改变尺寸；边锚点只改变该轴。
- Shift + 四角：内容与容器同步按拖动开始时的宽高比缩放。
- Ctrl（macOS 对应 Meta）+ 拖动：仅改容器，保持内容尺寸、字号及画布绝对位置。
- Ctrl + Shift + 四角：仅等比例改容器。
- 圆形、圆形光点、时钟四角默认保持原比例；边锚点仍支持单轴调整。
- 文字/数字使用原像素属性缩放逻辑；图表交给自身绘图逻辑重排，表格扩大显示区域，均不全局拉伸字号。
- 图片沿用原有 contain/cover 等适配配置，默认 Image 为 contain，不覆盖已有图片适配方式。
- 最小内容尺寸：一般组件 8×8；输入/按钮 40×24；普通表格 160×100；高级分页表格 320×160；图表 120×80，启用历史查询的图表高度至少120。已有小于这些限制的组件不跳大，以原尺寸作为缩小下限。Ctrl 调整容器下限1×1。
- 四角比例缩放保留亚像素尺寸，避免整数取整破坏比例；固定对侧边。拖动采用每帧更新，松手按最终坐标刷新；Escape 恢复，完成仅生成一次 UPDATE 历史。
- UPDATE 撤销/重做保持嵌套配置对象引用，避免使用 toRefs 的组件停留在旧字号；同时删除快照中不存在的字段。
- 锚点提供快捷键提示；线段保留上一批端点编辑方式，不改为八锚点拉伸。
