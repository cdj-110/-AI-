# 配置未保存误提示修复

EG100 实机只读诊断确认：未编辑任何字段，打开设备时前端仍把不存在的 `forwardDevices` 补为 `[]`，导致原始 JSON 比较产生差异，离开页面弹出未保存提示。

## 修改

- 配置读取后、交给页面渲染前，统一初始化编辑器必需的缺省项；建立保存基准时使用同样规则。只补缺省，不覆盖已有配置值。
- 移除浏览通道时触发的协议同步；设备协议同步和 OPC DA 协议默认参数仅在显式协议编辑时执行。
- 浏览转发设备不再根据来源点位改写已有转发名称和标识符。
- IEC61850 转发的对象引用同步仅响应同一设备/点位的实际编辑；切换设备、分页或重新加载不改写对象引用。
- 保存、重载及放弃修改后重新建立基准；实际编辑、JSON 编辑和无效 JSON 仍受离开保护。
- 绑定配置 store 到 TypeScript 源模块，避免旧的同名编译文件覆盖修改。

## 验证

`verify-config-draft-defaults.mjs`：缺省初始化、原值保留、重复初始化稳定。

`verify-config-draft-guard.mjs`：Modbus RTU、OPC DA、IEC104、Modbus 转发、IEC61850 MMS 转发首次进入及浏览无提示；实际编辑和显式协议切换有提示；改回原值、重新加载和放弃修改后无提示；浏览不重写点位和设备参数。

表格列宽及取消高亮回归、点位显示及删除导航回归、前端类型检查与生产构建通过。

本次未部署到 EG100，未保存或更改实机配置。
