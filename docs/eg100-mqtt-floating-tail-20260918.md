# EG100 MQTT 上报浮点尾差处理

## 范围

在网关 MQTT 上报层处理数字副本，覆盖微控云遥测、手动 MQTT 的平铺属性、分组和自定义模板（含单设备/单点引用）。不修改采集缓存、历史源值、告警计算、协议转发或控制写入。

示例报文：`{"mbrtu_P01":42.9,"mbtcp_P01":0}`。JSON 数字保持数字类型；原本的字符串不擅自转换为数字。

## 精度策略

不固定保留两位小数，不统一限制所有值的有效位数。仅当一个更短的十进制数与原 float64 相差不超过两个相邻浮点步长，且至少能减少四个有效数字时才修正。保留通常的高精度数据，例如 `1.2345678901234567`、`0.3333333333333333`，保留微小值、大整数及非数字类型。负零上报为零；NaN/Infinity 仍沿用原来的 JSON 编码失败机制，不伪造有效测量值。

任何通用浮点清理都无法完全区分故意设置的近十进制数与计算尾差，因此修正幅度明确限定为两个浮点步长。更强的计量精度需求应通过点位精度设置或独立十进制定点方案实现。

分组、嵌套 map 和数组均复制处理，避免修改共享读数。MQTT 主题、QoS、retain 策略和控制回执编码保持不变。
